# 电脑租赁网站 - 完整页面实例（文字版）


## 一、公共页面（无需登录）


### 第1页：登录页
路由：`/login`

布局：
```
+--------------------------------------------------+
|                                                    |
|                 电脑租赁管理系统                     |
|                                                    |
|                  [LOGO 图标]                       |
|                                                    |
|                                                    |
|          账号: [________________]                   |
|                                                    |
|          密码: [________________]                   |
|                                                    |
|          [ ] 记住我                                |
|                                                    |
|          [  登 录  ]                               |
|                                                    |
|          还没有账号？ [注册]                        |
|          [忘记密码？]                              |
|                                                    |
+--------------------------------------------------+
```

交互说明：
- 输入账号（用户名/邮箱）和密码
- 点击登录后验证身份，根据角色跳转：
  - ADMIN → `/admin/dashboard`
  - STAFF → `/staff/dashboard`
  - CUSTOMER → `/customer/dashboard`
- 密码错误3次后显示验证码输入框
- 密码使用bcrypt加密传输

字段说明：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 账号 | text | 是 | 用户名或邮箱 |
| 密码 | password | 是 | 密码输入 |
| 记住我 | checkbox | 否 | 记住登录状态 |


### 第2页：注册页
路由：`/register`

布局：
```
+--------------------------------------------------+
|                                                    |
|                 创建新账户                          |
|                                                    |
|          [LOGO]                                    |
|                                                    |
|          姓名: [________________]                   |
|                                                    |
|          邮箱: [________________]                   |
|                                                    |
|          密码: [________________]                   |
|                                                    |
|          确认密码: [________________]               |
|                                                    |
|          推荐人: [________________]                 |
|          (选填，填写推荐人ID或推荐码)               |
|                                                    |
|          [ ] 我已阅读并同意《用户协议》             |
|                                                    |
|          [  注 册  ]                               |
|                                                    |
|          已有账号？[去登录]                        |
|                                                    |
+--------------------------------------------------+
```

交互说明：
- 所有字段均为必填（除推荐人外）
- 密码长度至少8位，需包含字母和数字
- 密码和确认密码需一致
- 如填写推荐人，验证推荐人是否存在
- 注册成功后自动跳转至登录页

| 字段 | 数据来源 | 说明 |
|------|---------|------|
| 合同编号 | 系统生成 | 格式：CT + 日期 + 序号 |
| 乙方（承租方） | 客户填写 | 签署时填写的姓名 |
| 设备名称/型号/序列号 | 设备表 | 员工创建合同时选择 |
| 租赁起始日/结束日 | 员工填写 | 创建合同时设置 |
| 日租金/押金 | 设备表 + 员工填写 | 设备默认日租金 + 员工设置的押金 |
| 支付方式 | 客户选择 | 信用卡/银行转账/余额 |
| 支付状态 | 系统判断 | 已支付/待支付/支付失败 |
| 签署人 | 客户填写 | 签署时填写的姓名 |
| 签署时间 | 系统记录 | 支付成功时自动记录 |

交互说明：
- 完全公开访问，无需登录
- 已注册用户底部显示"返回我的账户"
- 未注册用户底部显示"注册账户绑定此合同"
- 支持打印和下载PDF功能
